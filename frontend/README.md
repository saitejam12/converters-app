# A frontend only application which will allow users

Build a frontend only application which will allow users to convert all types measurements into other types. Example categories  distances, weights, liquids, time, time zones, electricity etc. List the most commonly used conversions and add them to the app. keep it minimal

Generated by the Quorq AI SDLC platform from an approved app design.

Every screen here was generated from a design the team reviewed and approved,
and runs on **seeded sample data** -- there is no backend and no network call.
The prototype was approved on that basis; wiring it to real services is the
next job, not something this repository pretends to have done.

## Running it

```bash
npm install
npm run dev
```

## Layout

- `src/screens/` -- one module per approved screen.
- `src/App.tsx` -- the navigation shell and the route table.
- `src/lib/ui.tsx`, `src/lib/icons.tsx` -- the component and icon vocabulary
  the screens were written against.
- `src/lib/brand.ts`, `src/index.css` -- the approved brand, as tokens and as
  CSS variables.
