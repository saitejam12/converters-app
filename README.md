# A frontend only application which will allow users

Build a frontend only application which will allow users to convert all types measurements into other types. Example categories  distances, weights, liquids, time, time zones, electricity etc. List the most commonly used conversions and add them to the app. keep it minimal

Generated by the Quorq AI SDLC platform. Two applications, one repository:

- **`frontend/`** -- the approved app design as a Vite + React SPA. Every screen
  was reviewed and approved, and runs on seeded sample data.
- **`backend/`** -- a FastAPI service. No architecture had been approved
  when this repository was created, so it starts with its health check and
  nothing else.

## Running it

```bash
cd frontend
npm install
npm run dev
```

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
pytest
```
